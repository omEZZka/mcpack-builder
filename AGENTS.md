# AGENTS.md — MCPack Builder

Перед любой работой в этом проекте **обязательно прочитай** файл `PROJECT_INSTRUCTION.md` в корне репозитория — там краткая выжимка архитектуры, стека, модулей, сборки и известных проблем.

Дополнительные правила:
- Язык интерфейса — русский.
- Пакет: `com.mcpackbuilder`.
- Комментарии не добавлять без явной просьбы.
- Не коммитить без явной просьбы пользователя.
- Перед коммитом запускать `git diff --check`.
- Версию (`versionCode`/`versionName`) обновлять в `app/build.gradle.kts`, а не только в имени APK.
